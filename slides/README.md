## ★ 같은 그림의 사본은 자동으로 동기화되지 않는다

`00_overview.svg` 는 지금 세 폴더에 각각 들어 있다. 공유가 아니라 **의도적인 사본**이다.
문서마다 강조점이 달라질 수 있으니 따로 손보라고 그렇게 두었다.

대가가 하나 있다 — **한 곳만 고치고 넘어가기 쉽다.** 조감도를 수정했다면 나머지도
고칠 것인지 매번 판단해야 한다. 지금 갈라졌는지 확인하는 방법:

```bash
md5sum slides/*/00_overview.svg
```

해시가 다르면 갈라진 것이다. 그게 의도한 것이면 그대로 두면 된다.

## 새 그림을 추가할 때

1. **쓸 문서의 폴더에 넣는다.** 문서가 여러 개면 각각에 사본을 둔다.
2. 여러 문서가 쓰는데 해당 폴더가 없으면 문서 이름으로 새로 만든다.
3. [STRUCTURE.md](../STRUCTURE.md) 의 트리에 반영한다.
4. 문서에서 참조할 때는 **저장소 최상위 기준 상대 경로**를 쓴다.

```markdown
![전체 조감도](slides/README/00_overview.svg)
```

### SVG 를 직접 쓸 때 주의할 것

이 슬라이드들을 만들면서 실제로 겪은 문제들이다.

* **`<marker>` 화살촉을 쓰지 말 것.** PowerPoint 와 일부 뷰어에서 렌더링되지 않는다.
  화살표 끝에 `<polygon>` 을 명시적으로 그린다.
* **위첨자를 `tspan dy` 로 만들지 말 것.** 겹쳐 보인다. `2^b`, `Q+ / Q-`, `Q·K^T` 처럼
  ASCII 로 적는다.
* **한글 폰트를 파일에 지정하지 말 것.** 뷰어마다 없을 수 있다. 일반 `sans-serif` 로 두면
  대부분 환경에서 맑은 고딕으로 대체된다.
* **글자가 상자를 넘지 않는지 확인할 것.** 브라우저에서 열어 눈으로 보는 것이 가장 빠르다.
  실제로 `00_overview.svg` 는 넘침을 세 번 고쳤다.
